# App Package

## Σκοπός

Ο φάκελος `app` είναι ο κύριος application package του backend.  
Περιέχει όλο τον οργανωμένο Python κώδικα της εφαρμογής και αποτελεί το βασικό επίπεδο υλοποίησης του συστήματος.

Ο στόχος του είναι να χωρίζει την εφαρμογή σε σαφή τεχνικά επίπεδα, ώστε κάθε μέρος να έχει συγκεκριμένη ευθύνη.

## Τι περιέχει

- API routes και versioning
- Core configuration
- Database layer
- Models
- Schemas
- Services
- Application entrypoint

## Αρχιτεκτονική λογική

Η δομή του `app` βασίζεται στις παρακάτω αρχές:

- Τα endpoints δεν πρέπει να περιέχουν βαριά επιχειρησιακή λογική
- Η λογική της εφαρμογής πρέπει να πηγαίνει στα services
- Η πρόσβαση στη βάση πρέπει να οργανώνεται μέσα από το database layer
- Τα requests και responses πρέπει να ελέγχονται από schemas
- Τα models πρέπει να αναπαριστούν σωστά τις οντότητες του domain

## Στόχος

Το `app` είναι η βάση πάνω στην οποία θα αναπτυχθούν τα modules της πλατφόρμας, ξεκινώντας από το module της Καθαριότητας και Αποκομιδής.
