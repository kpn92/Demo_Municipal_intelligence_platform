# Models

## Σκοπός

Ο φάκελος `models` περιέχει τα SQLAlchemy ORM models της εφαρμογής.

Τα models αναπαριστούν τις βασικές οντότητες του συστήματος σε επίπεδο κώδικα και συνδέονται άμεσα με τη δομή της βάσης δεδομένων.

## Τι περιέχει

- table definitions
- πεδία και τύπους δεδομένων
- primary keys
- foreign keys
- constraints
- relationships
- indexes

## Ρόλος

Τα models είναι η γέφυρα ανάμεσα στη λογική της εφαρμογής και στη βάση δεδομένων.

Αποτελούν την επίσημη αναπαράσταση των επιχειρησιακών οντοτήτων του έργου.

## Παραδείγματα μελλοντικών οντοτήτων

- `sector.py`
- `employee.py`
- `vehicle.py`
- `shift.py`
- `daily_assignment.py`
- `work_task.py`

## Σημείωση σχεδίασης

Τα models πρέπει να μένουν όσο γίνεται καθαρά και να περιγράφουν κυρίως τη δομή και τις σχέσεις των δεδομένων.  
Η σύνθετη επιχειρησιακή λογική πρέπει να τοποθετείται στα services.
