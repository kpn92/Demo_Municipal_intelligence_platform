# Core Layer

## Σκοπός

Ο φάκελος `core` περιέχει τις κεντρικές ρυθμίσεις και τα θεμελιώδη δομικά στοιχεία της εφαρμογής.

Εδώ μπαίνουν τα στοιχεία που αφορούν ολόκληρο το backend και χρησιμοποιούνται από πολλά μέρη του συστήματος.

## Τι περιέχει

- application settings
- environment configuration
- constants
- security helpers
- γενικά κοινά utilities υψηλού επιπέδου

## Ρόλος

Ο φάκελος αυτός λειτουργεί ως το κεντρικό σημείο ρύθμισης της εφαρμογής.  
Στόχος είναι να μην υπάρχουν hardcoded τιμές διασκορπισμένες στον κώδικα.

## Παραδείγματα μελλοντικών αρχείων

- `config.py`
- `constants.py`
- `security.py`

## Σημείωση

Οτιδήποτε αφορά γενική συμπεριφορά του backend και όχι μια συγκεκριμένη επιχειρησιακή οντότητα, ανήκει συνήθως στο `core`.
