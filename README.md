# Smart City Operations Platform

**A full-stack GIS-based operations management platform for city municipalities.**  
Covers two core modules: **Street Cleaning (1A)** and **Waste Collection (1B)** — each with real-time map visibility, daily assignment workflows, and PDF/Excel reporting.

## Features

### Module 1A — Street Cleaning
- Interactive map with road network, cleaning zones, and sector overlays (MapLibre GL JS)
- Daily assignment wizard: assign crews, sectors, and shifts in 4 guided steps
- PDF export of daily cleaning plans with embedded GeoTIFF map backgrounds and QR codes
- Real-time KPI strip (active sectors, assigned employees, pending roads)
- Sector filtering and pending-roads panel

### Module 1B — Waste Collection
- Fleet management: vehicles, waste bins, collection routes
- Bin fill-level heatmap visualization
- Collection history with timeline and completion tracking
- Excel and PDF export for collection reports
- Assignment wizard for daily route planning

### Platform
- JWT authentication with role-based access (admin, supervisor, fleet operator)
- GIS geometry stored in PostGIS (EPSG:2100), served as GeoJSON (EPSG:4326)
- 23 Alembic database migrations tracking full schema evolution
- OpenAPI docs auto-generated by FastAPI

## Getting Started

### Prerequisites
- Python 3.11+
- Node.js 20+
- Docker (for local database)

### 1. Clone the repo

```bash
git clone https://github.com/kpn92/Demo_Municipal_intelligence_platform.git
cd Demo_Municipal_intelligence_platform
```

### 2. Start the database

```bash
docker compose up -d
```

### 3. Backend setup

```bash
cd backend
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env
# Edit .env with your DATABASE_URL and SECRET_KEY

alembic upgrade head
uvicorn app.main:app --reload
```

API available at `http://localhost:8000`  
Docs at `http://localhost:8000/docs`

### 4. Frontend setup

```bash
cd frontend-react
npm install

cp .env.example .env.local
# Edit .env.local — set VITE_API_URL=http://localhost:8000

npm run dev
```

Frontend available at `http://localhost:5173`

## API Overview

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/v1/auth/login` | JWT authentication |
| `GET` | `/api/v1/sectors` | List all city sectors |
| `GET` | `/api/v1/mapping/layers` | GeoJSON layers for map |
| `GET` | `/api/v1/fleet/vehicles` | Fleet vehicle list |
| `GET` | `/api/v1/fleet/bins` | Waste bin locations + fill levels |
| `GET` | `/api/v1/collection-history` | Collection event history |
| `POST` | `/api/v1/cleaning-plan-assignments` | Create daily cleaning assignment |
| `GET` | `/api/v1/cleaning-plan-assignments/{id}/pdf` | Export assignment as PDF |

Full interactive docs: `/docs` (Swagger UI)
